% ============================================================================
% Aviation App Privacy - FlowDroid sources & sinks
% ----------------------------------------------------------------------------
% Purpose: find where personal data in aviation apps (airlines, flight trackers,
% EFB/pilot tools, drone apps) is collected and where it goes - so it can be
% compared against each app's privacy policy / Play Store Data Safety label.
%
% Built Nov 2026. Every Android/SDK signature below was checked against method
% references found in the project's own APKs (20 apps), so they match how the
% apps actually call these APIs.
%
% Format (FlowDroid):  <class: returnType method(paramTypes)> [permission] -> _SOURCE_ | _SINK_
% Lines starting with % are comments.
%
% Category headers ("% @category SOURCE|SINK: NAME") are read by
% flow_droid_script.py to label each leak in leaks.csv. FlowDroid ignores them.
%
% Deliberately LEFT OUT vs. FlowDroid's default file (they caused most of the noise):
%   - Intent / Bundle getters & putters as sources/sinks (data passed between screens)
%   - Locale.getCountry() etc. (not personal data)
%   - SharedPreferences putInt / putBoolean (settings, not personal data)
%   - Old server-side Java libraries (Spring, servlet, xmlrpc)
% Optional extras are at the bottom, commented out.
% ============================================================================

% ############################################################################
% SOURCES - where personal data comes from
% ############################################################################
